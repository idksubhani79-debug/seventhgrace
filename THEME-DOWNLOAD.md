# Seventh Grace custom Horizon theme

Download **seventhgrace-horizon-complete.zip** from this branch. This is a complete theme, not the earlier Dawn add-on.

[Download the theme ZIP](https://github.com/idksubhani79-debug/seventhgrace/raw/refs/heads/codex/seventhgrace-horizon-theme/seventhgrace-horizon-complete.zip)

1. Keep the downloaded file zipped.
2. In Shopify, open **Online Store → Themes → Add theme / Import theme → Upload ZIP file**.
3. Upload it as a new unpublished theme, then open **Customize / Edit theme**.
4. On the homepage, select the collection and bundle product under **Seventh Grace original**.
5. Under **Theme settings → Seventh Grace**, configure category collections, contact details, navigation, and the size guide.
6. Preview and test real products, stock limits, cart, shipping, payments, email forms and apps before publishing.

Built from the supplied Horizon 4.2.0 export using the original HTML design. Local validation: 5 browser integration tests passed using Shopify API fixtures; Shopify Theme Check reported 0 errors and 42 warnings. Live Shopify checkout and backend behavior still require store validation.

Only the download ZIP and this guide are added on this branch.
